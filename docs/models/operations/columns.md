# Columns

Columns to include in the CSV, in order. Defaults to email, started_at, product, amount, currency, status and recurring_interval.


## Supported Types

### `components.SubscriptionExportColumn`

```typescript
const value: components.SubscriptionExportColumn = "amount";
```

### `components.SubscriptionExportColumn[]`

```typescript
const value: components.SubscriptionExportColumn[] = [
  "current_period_end",
];
```
